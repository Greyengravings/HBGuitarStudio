# Audio Sample Files for Explore Page

This directory should contain the following audio files:

## Guitar Samples:
- **acoustic-guitar.mp3** - 30-second sample of acoustic guitar playing
- **electric-guitar.mp3** - 30-second sample of electric guitar playing  
- **bass-guitar.mp3** - 30-second sample of bass guitar playing

## Other Instruments:
- **harmonium.mp3** - 30-second sample of harmonium playing
- **ukulele.mp3** - 30-second sample of ukulele playing

## Audio File Requirements:
- Format: MP3
- Duration: 20-30 seconds each
- Quality: 128kbps or higher
- Content: Clear instrument demonstration

## Sample Audio Sources:
You can use:
- Royalty-free audio from Freesound.org
- Creative Commons licensed samples
- Own recorded samples
- AI-generated audio samples (ensure licensing)

## Implementation Notes:
- Audio files should demonstrate the unique sound of each instrument
- Include a variety of playing techniques if possible
- Keep file sizes reasonable for web loading
- Test audio playback functionality in browsers
