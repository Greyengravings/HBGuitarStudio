## 📄 Complete Website Structure

### **4 Main Pages:**

1. **🏠 Home Page**
   - Video hero section with background video
   - Scrolling carousel of instrument cards
   - About the master section with photo and description
   - Footer with quote and contact information

2. **🎵 Explore Page** (NEW - Enhanced Feature)
   - Interactive instrument showcase
   - Audio player for each instrument
   - Play/pause controls with progress bar
   - Time display functionality
   - Guitar, Harmonium, Bass Guitar, and Ukulele sections

3. **📚 Courses Page**
   - Guitar courses (Acoustic, Electric, Bass)
   - Harmonium courses (Traditional, Electronic)
   - Detailed course descriptions and pricing
   - Enroll buttons for each course

4. **📞 Contact Page**
   - Contact information and studio address
   - Enrollment form for classes
   - Google static map integration
   - Interactive contact form
